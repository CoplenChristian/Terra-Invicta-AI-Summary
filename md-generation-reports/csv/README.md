# Exported CSV Data

This directory contains the **raw data files** exported from the Terra Invicta save file.

## 🔄 Generation
These files are generated by running the export script:
```powershell
.\export_factions.ps1
```
*Note: This script reads the save file defined in `../../config.json` (the ignored config at the repository root) and populates this folder.*

## 📂 File Types

- **`Again_Factions_Core.csv`**: High-level faction data (Money, Influence, Boost, etc.).
- **`Again_Faction_EarthSummary.csv`**: Aggregated Earth control stats (CPs, GDP, Pop).
- **`Again_Faction_HabIncome.csv`**: Space resource income per faction.
- **`Again_<Faction>_Nations.csv`**: Detailed control point data for each faction's nations.
- **`Again_HabSites.csv`**: Comprehensive list of all hab sites and their resources/ownership.
- **`Again_SpaceBodies.csv`**: Metadata for all celestial bodies.
- **`Again_Techs_Global.csv`**: Global research status.

## ⚠️ Do Not Edit
These files are overwritten every time the export script runs. Do not manually edit them if you want your changes to persist.
