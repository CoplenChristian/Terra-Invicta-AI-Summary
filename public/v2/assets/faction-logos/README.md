# Faction logos

UI council emblems extracted from the local Terra Invicta Unity asset bundle:

`TerraInvicta_Data/StreamingAssets/AssetBundles/faction_logos`

Files are the `councilIcon256_ui` textures, named by `TIFactionTemplate.dataName`.

These are Pavonis Interactive / Terra Invicta art, kept here only so the campaign dashboard can render faction identity. Do not redistribute as a standalone asset pack.
