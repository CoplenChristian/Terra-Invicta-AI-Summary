# Snippet Packs

This directory contains **raw Markdown data dumps** generated by the Terra Invicta toolbox.

## 📄 File Naming
`snippet_pack_YYYYMMDD.md` (where `YYYYMMDD` is the in-game date).

## 🛠️ Generation
These files are created using the PowerShell command:
```powershell
Get-TISnippetPackMarkdown | Set-Content -Encoding UTF8 .\Again_Save\snippet_pack\snippet_pack_YYYYMMDD.md
```

## 💡 Usage
1.  Open a snippet pack file.
2.  Copy the relevant tables and sections.
3.  Paste them into your dated summary file in the `../summary/` directory (or `../` depending on your workflow).
4.  These snippets provide the **source data** for your strategic analysis.
