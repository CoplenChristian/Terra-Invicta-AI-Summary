# Strategic Summaries

This directory contains the **finalized, dated strategic reports** for the campaign.

## 📄 File Naming
`summary_YYYYMMDD.md` (where `YYYYMMDD` is the in-game date).

## 📝 Creation Process
1.  **Template**: The master template is located at `../summary.md`.
2.  **Data Source**: Use the raw data from `../snippet_pack/`.
3.  **Content**: Each summary combines the raw data tables with human (or AI) strategic analysis, identifying key trends, threats, and action plans.

## 🗂️ Organization
Keep your summaries here to maintain a history of the campaign's progress and your strategic thinking over time.
